# Asciicut Brand Assets — Nibbles the Beaver

This directory contains the official brand assets, icons, and illustrations featuring **Nibbles the Beaver**, the official mascot of Asciicut.

## File Index & Usage Guidelines

### 1. Logo & Mascot Branding
* **`logo_master.png`**
  * *Description:* Nibbles wearing safety goggles holding giant scissors, with a soft warm studio backdrop.
  * *Best Used For:* Large presentation screens, printed materials, installers, or static pages with light backgrounds.
* **`logo_master_transparent.png`**
  * *Description:* The master mascot logo with the background fully keyed out.
  * *Best Used For:* Web landing page headers, GitHub READMEs, and overlays across dark, light, or colored background panels.

### 2. Icons & Favicons
* **`logomark_head.png`**
  * *Description:* A simplified, close-up icon of Nibbles' head with goggles on a solid white background.
  * *Best Used For:* Standard circular profiling on solid light canvases.
* **`logomark_head_transparent.png`**
  * *Description:* The logomark head icon with transparent backing.
  * *Best Used For:* Web app favicons, mobile/desktop application launcher icons, browser tabs, organization logos, and dark theme UI status bars.
* **`app_icon.png`**
  * *Description:* A launcher-optimized square icon with rounded corners, featuring the mascot head on a premium dark slate background.
  * *Best Used For:* Windows, macOS, and Linux desktop environment launch shortcuts (e.g., Tauri `.ico`/`.icns` source target).

### 3. Interactive UI States
* **`ui_empty_state.png` / `ui_empty_state_transparent.png`**
  * *Description:* A confused Nibbles tangled up in terminal-text tape ribbons.
  * *Best Used For:* Empty state views (e.g., "No asciicast file loaded", "No search results match", or "Recents list is empty").
* **`ui_loading.png` / `ui_loading_transparent.png`**
  * *Description:* Nibbles running in a hamster wheel tape drive to power a progress bar.
  * *Best Used For:* Loading screen states during WASM initialization, recording parses, or video compositions.

### 4. Social & Presentation Banners
* **`social_banner.png`**
  * *Description:* A premium 1280x640px banner containing Nibbles and a code compilation mockup on a dark slate background.
  * *Best Used For:* GitHub repository social cards, npm landing headers, and community forum headers.

---

## Technical Specifications
* **Format:** PNG-24 (Alpha channel enabled on `_transparent` variants).
* **Color Palette Reference:**
  * Mascot body: Brown (`#7E5A44`)
  * Goggles & Highlights: Yellow (`#FCD116`)
  * Code/Ribbons: Neon Green (`#39FF14`)
  * Premium background canvas: Slate Blue (`#1A1B26`)
